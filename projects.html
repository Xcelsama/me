Naija Vox

Flagship. Runs fully in the browser

A Nigerian text-to-speech studio with six Nigerian-accent voices that read English, Pidgin, Yoruba, Igbo and Hausa. It supports tags like [softly] and [pause:500ms], sound effects, and exports to WAV, MP3, SRT and WebM. No server and no API key.

  • Web Speech
  • Audio export
  • Live site
