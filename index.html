01. About

More Than Code

I’m a graphic designer and self-taught full-stack developer from Port Harcourt, Nigeria. I design posters, flyers and interfaces, and I build them into web apps that people can actually use: file tools that run in the browser, systems for churches and small businesses, and products built with a team.

Beyond that, I edit photos and publish them in my own gallery, make videos of one to three minutes for TikTok and run live production for a church media team. Design and code feed each other: I build tools for my own editing, and I can design the visuals a product needs.
